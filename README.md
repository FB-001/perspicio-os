# Perspicio OS

**Simples para usar, privado por princípio.**

O Perspicio OS é um sistema operacional baseado inicialmente no Debian, criado para oferecer uma experiência simples, prática e respeitosa com a privacidade do usuário.

## Objetivo

Simplificar o uso do computador sem exigir conhecimentos técnicos, contas on-line obrigatórias ou entrega desnecessária de dados pessoais.

## Princípios

* privacidade por padrão;
* simplicidade;
* liberdade de escolha;
* transparência;
* controle local;
* ausência de telemetria própria;
* segurança sem retirar o controle do usuário.

## Base inicial

* Debian 13 “Trixie”;
* arquitetura amd64;
* KDE Plasma;
* interface familiar para usuários vindos do Windows;
* identidade visual própria, moderna e simples.

## Estado do projeto

O Perspicio OS está em fase inicial de planejamento e desenvolvimento. Ainda não existe uma imagem ISO disponível para uso.

A visão completa está disponível em [docs/VISION.md](docs/VISION.md).
